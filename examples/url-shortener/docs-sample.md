## Module: `UrlShortener`

URL shortener — surface specification.

The user-visible contract: an Owner registers a short slug pointing at
a URL; a Visitor later visits the slug and is redirected. Slugs are
unique across all owners.

## What an Owner can do

### `create(s, target)` — register a new short link

Owner `o` registers a new slug `s` pointing at `target`.

**Preconditions:** the slug must be free.

**Outcome:** the slug is bound to the target. A `Created` event is
emitted to all observers.

**Errors:**

| Error name  | When it happens                  |
|-------------|----------------------------------|

## What a Visitor can do

### `visit(s)` — follow a short link

Visitor `v` requests slug `s` and is redirected to its target URL.
Returns the target URL so callers can use it directly.

**Preconditions:** the slug must exist.

**Outcome:** a `Visited` event is emitted; the target URL is returned
to the caller (and recorded as a `Returned<Visit>` event observable
to the visitor).

**Errors:**

| Error name | When it happens                |
|------------|--------------------------------|
| `NotFound` | The slug `s` is not registered. |

**Boundary checklist** *(from §6.4 mandatory slots, v0.9)*

| Slot            | Value                                                              |
|-----------------|---------------------------------------------------------------------|
| Idempotency     | Idempotent — re-visiting yields the same redirect.                  |
| Auth channel    | Anonymous — no authentication required.                              |
| Retention       | Ephemeral — not durably stored beyond the request.                   |
| Rate limit      | 10,000 per slug per minute.                                          |
| Observability   | Caller-only — `Visited` is delivered to the Visitor who requested it. |
| Availability    | Critical — read path; downtime is incident-level.                    |

# Worked use cases

## "register then visit" *(safety scenario)*

> Owner `O` registers `"go"` pointing at `https://example.com`. Then
> Visitor `V` visits `"go"`.
>
> The system promises: `V` is redirected to `https://example.com`,
> and a `Visited` event records the redirect.

```
Given: links == {} ; owners == {}
When:  O does create("go", "https://example.com")
       V does visit("go")
Then:  resolves("go") == Some("https://example.com")
       observed Visited(slug="go", target="https://example.com", by=V) by V
```

## "creating a taken slug raises SlugTaken" *(safety scenario)*

> Owner `A` already owns `"go"`. Owner `B` tries to register the same
> slug.
>
> The system promises: `B`'s `create` deterministically fails with
> `SlugTaken`. No state changes.

```
Given: links  == { "go": "https://a.example" }
       owners == { "go": A }
When:  B does create("go", "https://b.example")
Then:  fails with SlugTaken
```

## "every registered slug is eventually visitable" *(liveness scenario)*

> Owner `O` registers `"go"`; Visitor `V` visits `"go"`.
>
> The system promises: `V` is *eventually* redirected (the system
> doesn't get stuck before serving the visit).

```
Given: links == {} ; owners == {}
When:  O does create("go", "https://example.com")
       V does visit("go")
```

## Substrate `InMemoryStore`

A single in-memory store: one component (`Store`) holds two maps,
slug → URL and slug → owner.

### Component `Store`

| Field           | Type                | Meaning                                  |
|-----------------|---------------------|------------------------------------------|
| `table`         | `Map[Slug -> Url]`  | The slug-to-URL mapping.                 |
| `registered_by` | `Map[Slug -> Owner]`| The owner of each slug.                  |

### Surface ↔ substrate mapping

| Surface field | Substrate value                |
|---------------|--------------------------------|
| `links`       | `Store.table`                  |
| `owners`      | `Store.registered_by`          |

### Realization

| Surface action       | Realised by              | When                                                             |
|----------------------|--------------------------|------------------------------------------------------------------|
| `create(s, target)`  | `Store.put(s, target, o)` | `Store.put.s == s && Store.put.target == target`                |
| `visit(s)`           | `Store.lookup(s, v)`      | `Store.lookup.s == s`                                            |

parameter:
